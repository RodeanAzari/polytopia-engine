## Pilot SPRTs slower than planned: diagnosis
- **Symptom:** each of the two pilot SPRTs at 8 jobs ran about 28 games/h (games 15–18 min each), so a
  200-game batch took ~7 h. Restarted at 32 jobs each (03:05; finished games kept, in-flight games lost):
  14 games in the next 55 min, i.e. worse.
- **Measurements:**
  - Per-thread CPU: the batcher thread at 100% (mostly spinning in the CUDA stream synchronisation); the 32
    game threads together under one core.
  - Process A's game-thread work rate with B running vs. B paused (SIGSTOP), 30 s each: 999 vs. 2,270 ticks
    (×2.3); GPU 92% vs. 69%. Two processes sharing the GPU time-slice badly (two CUDA contexts, WSL2).
  - One process alone, 32 jobs, POLY_EVAL_LOG (`3027076`): 6,935 positions/s over 120 s, mean batch 31.9, all
    CUDA graphs, 3.8 ms per batch in forward, fill-wait 2.7% of the time.
- **Root cause:** GPU throughput, not a bug. A net agent's game needs on the order of 600k evaluations (~300
  searched decisions × 2,000) [rough estimate, not measured per game], so one process gets roughly 40 games/h
  at best, and two processes get less in total than one.
- **Response (04:40):** the `leaf=diff` tournament paused (SIGSTOP; in-flight games kept); `leaf=net`
  continues alone at 32 jobs; a watcher resumes `leaf=diff` when the `leaf=net` SPRT ends. 64 jobs was not
  possible: 7 GB of memory available (another process holds 12.7 GB).
- **Interim, batch 1 only (no SPRT verdict):** `leaf=net` 85/137 = 62.0% (53.7–69.7%); `leaf=diff` 61/123 =
  49.6% (40.9–58.3%) — first-finished games, read with care.

## Bug: tournaments with a network agent aborted at exit
- **Symptom:** both pilot SPRT scripts stopped after batch 1 with no SPRT line; `.out` showed
  `c10::AcceleratorError: CUDA error: driver shutting down` from a TensorImpl destructor at exit. All 200 games
  of each batch were written. The `leaf=net` one stopped at 06:38 and `leaf=diff` (auto-resumed) at 08:11;
  nothing ran from 08:11 to 10:50.
- **Root cause:** the shared evaluators were function statics, destroyed after the CUDA runtime's own teardown.
- **Fix (`8628966`):** a guard first in `main` clears them. Regression test
  `test_tournament_with_a_network_agent_exits_cleanly` (aborted the same way before the fix).
