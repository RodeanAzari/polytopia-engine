## Action encoding (ADR-006, proposed)
- Scratch measurement (not committed; random games on the 1,200 bench levels, both obs modes, 3.1M legal sets):
  a tile-based key (location tile, type, offset or parameter, relative tribe, amount) never collides; legal-set
  size mean ~50, p99 245/179, max 416/353; Send stars is ~45% of all legal actions.
- **My bound was wrong:** I derived max move offset 6 (2 × movement 3, half-step roads); measured 7 (knights).
  Root cause: halved "rest" costs on forest/mountain roads aren't multiples of 0.5, so cost can end between M and
  M + 1, where `floor(c + s) ≤ M` still accepts a step. Correct bound: each step ≥ 0.5 and c + s < M + 1 →
  ≤ 2M + 1 = 7 steps. Window is [−7, 7]²; ADR records the derivation and the correction.

## Action encoding implemented (ADR-006 accepted by the user)
- `sim/include/poly/action_encoding.hpp`: `encode_action(obs, a)`, `decode_action(obs, legal, index)` (by
  matching), `detail::encode_in` (tests compare the observation with the true state).
- First property-test run: every per-action check passed but coverage failed (types 1, 20, 22 never seen).
  Cause: my setup gave every tech (nothing to research), 20-turn games make no veterans, fog games rarely let a
  Mind Bender reach an enemy. Fix: withhold Trade and Aquatism, start capital units at 3 kills, 30 turns.
- Bug injection: 7/7 caught (list in the ADR outcome). The first harness run reported 3 "not caught" that were
  the harness itself (an injection that didn't compile; two patterns not matching clang-format's reflow);
  re-run against the exact text, all caught. A reversed attack offset is caught only by the hand-computed case:
  it stays injective, so the property test can't see it.
- 1,200 bench levels: 155,232,869 legal actions encoded, 0 failures (scratch tool, both modes).
- `make ci` first failed on clang-tidy (16 findings in the new files: math parentheses, designated initializers,
  test helpers too complex). I almost missed it: piping `make ci` into `grep` hid the exit status. Check the
  real exit code. Fixed by splitting the test helpers (the random level is now table-driven with the same draws);
  the 7 bug injections re-run on the restructured tests, all caught again.
